Інтерактивна програма на C++, яка моделює рух подвійного маятника та порівнює дві траєкторії з близькими початковими умовами.

У вікні одночасно показано два запуски:
- **Run A — reference:** маятник із базовими початковими умовами.
- **Run B — perturbed:** маятник, у якого початковий кут другого вантажу додатково змінено на задану величину.

Це дає змогу спостерігати, як невелика зміна початкових умов впливає на подальший рух системи.

## Можливості програми

- Моделювання руху подвійного маятника.
- Одночасне порівняння двох запусків.
- Відображення маятників і слідів руху вантажів.
- Чисельне інтегрування методом Рунге — Кутти 4-го порядку (RK4).
- Налаштування початкових кутів, прискорення вільного падіння та різниці між запусками.
- Пауза, продовження та перезапуск моделювання.
- Зміна швидкості симуляції.
- Відображення часу, параметрів і стану симуляції у вікні.

## Використані технології

## Опис основних структур і класів

### `State`

Зберігає поточний фізичний стан маятника:
- `theta1` — кут першого стрижня, у радіанах;
- `omega1` — кутова швидкість першого стрижня;
- `theta2` — кут другого стрижня, у радіанах;
- `omega2` — кутова швидкість другого стрижня.

Ці значення змінюються під час чисельного моделювання.

### `Derivative`

Містить похідні величин зі структури `State`: швидкості зміни кутів і кутові прискорення. Структура використовується під час обчислення одного кроку методу RK4.

### `Parameters`

Зберігає параметри фізичної системи:
- `mass1`, `mass2` — маси вантажів;
- `length1`, `length2` — довжини стрижнів;
- `gravity` — прискорення вільного падіння;
- `initialAngle1`, `initialAngle2` — початкові кути в градусах;
- `perturbation` — додаткова зміна початкового кута другого маятника для запуску B.

Початкові значення: маси — 1 кг; довжини — 1,55 м і 1,45 м; `gravity = 9.81 м/с²`; кути — 120° і 12°; додаткова зміна — 0,5°.

### `DoublePendulum`

Клас, що відповідає за фізичну модель одного подвійного маятника: зберігає його параметри й стан, обчислює рух, відстежує час та накопичує точки траєкторії.

#### Публічні методи класу

| Метод | Призначення |
|---|---|
| `DoublePendulum(parameters, secondAngleOffset)` | Створює маятник із переданими параметрами та, за потреби, додатковим зсувом початкового кута другого стрижня. |
| `reset(secondAngleOffset)` | Повертає маятник до початкового стану, обнуляє час і очищає траєкторію. |
| `setParameters(parameters, secondAngleOffset)` | Застосовує нові параметри та перезапускає маятник із ними. |
| `advance(frameSeconds)` | Просуває фізичну симуляцію на заданий проміжок часу. Усередині використовується фіксований крок інтегрування. |
| `firstBobPosition()` | Повертає координати першого вантажу відносно точки підвісу. |
| `secondBobPosition()` | Повертає координати другого вантажу відносно точки підвісу. |
| `state()` | Повертає поточний фізичний стан маятника. |
| `trail()` | Повертає збережені точки траєкторії другого вантажу. |
| `elapsed()` | Повертає час, який минув у симуляції цього маятника. |

#### Внутрішні методи класу

| Метод | Призначення |
|---|---|
| `derivative(state)` | За поточними кутами та кутовими швидкостями обчислює похідні й кутові прискорення на основі рівнянь руху подвійного маятника. |
| `addScaled(state, derivative, scale)` | Створює допоміжний стан, додаючи до кожної величини її похідну, помножену на заданий масштаб. Використовується для проміжних оцінок у методі RK4. |
| `integrateRK4(dt)` | Обчислює наступний стан системи методом Рунге — Кутти 4-го порядку з кроком `dt`. |

Метод `advance()` накопичує час кадру й викликає `integrateRK4()` із фіксованим кроком `DT = 0.002 с`. Це зменшує залежність чисельного результату від частоти оновлення графічного вікна. Точки траєкторії додаються приблизно через кожні `0.018 с`; кількість збережених точок обмежена, щоб список не зростав безкінечно.

Усі наведені нижче функції, крім `main()`, розташовані в анонімному просторі імен. Це означає, що вони призначені для внутрішнього використання в цьому файлі.

| Функція | Призначення |

| `toDegrees(radians)` | Перетворює кут із радіанів у градуси. У поточній версії програми функція визначена, але не використовується. |
| `loadFont(font)` | Послідовно перевіряє кілька типових шляхів до шрифтів Windows і відкриває перший доступний шрифт. Повертає `true`, якщо шрифт вдалося завантажити. |
| `drawText(window, font, value, size, position, color)` | Створює та малює текст у вікні за заданими шрифтом, розміром, координатами й кольором. |
| `drawLine(window, a, b, color, thickness)` | Малює лінію між двома точками. Використовується для зображення стрижнів маятника. |

| `number(value, precision)` | Перетворює числове значення на текст із фіксованою кількістю знаків після десяткової крапки. Використовується для виведення параметрів на екран. |

### Функція `main()`

`main()` — точка входу в програму. Вона створює графічне вікно SFML, завантажує шрифт, задає початкові параметри та створює два об’єкти `DoublePendulum`: для запусків A і B.

Далі виконується головний цикл програми, який працює, поки вікно відкрите. На кожній ітерації він:
1. Визначає час, що минув від попереднього кадру.
2. Обробляє події вікна та натискання клавіш.
3. Якщо симуляція не призупинена, оновлює обидва маятники.
4. Очищає вікно та малює заголовок, панелі, маятники й інформацію про параметри.
5. Відображає готовий кадр.

Лямбда-функція `resetBoth` усередині `main()` перезапускає обидва маятники з поточними параметрами: для A без додаткової зміни кута, а для B — із параметром `perturbation`.

## Встановлення та запуск у Windows

### Необхідні компоненти

1. Visual Studio 2022 із робочим навантаженням **Desktop development with C++**.
2. CMake версії 3.20 або новішої.
3. Менеджер пакетів vcpkg.

Змінна середовища `VCPKG_ROOT` має вказувати на каталог, де встановлено vcpkg.

### Збирання

Відкрийте каталог проєкту у Visual Studio 2022 як проєкт CMake. Залежності проєкту описані у файлі `vcpkg.json`.

Також збирання можна виконати з термінала в кореневому каталозі проєкту:

```powershell
cmake --preset default
cmake --build build
```

Якщо у `CMakePresets.json` використовується інша назва пресета, замініть `default` на відповідну назву. Точний шлях до виконуваного файла залежить від конфігурації CMake та генератора.

## Усунення поширених проблем

- **Не вдається знайти SFML:** перевірте встановлення vcpkg, значення `VCPKG_ROOT` і наявність залежності у `vcpkg.json`.
- **CMake не конфігурує проєкт:** перевірте встановлення CMake та інструментів C++ у Visual Studio.
- **Програма не знаходить шрифт:** програма перевіряє кілька стандартних шляхів до шрифтів Windows. Якщо жоден не доступний, додайте `arial.ttf` поруч із виконуваним файлом.
- **Виникає помилка через відсутню DLL:** переконайтеся, що потрібні DLL доступні поруч із виконуваним файлом або в каталозі зі змінної середовища `PATH`.
