# Гравітаційна система N тіл

## 1. Опис програми
Програма реалізує комп'ютерну модель гравітаційної взаємодії кількох тіл. Вона дозволяє спостерігати за рухом тіл під впливом взаємного гравітаційного притягання, досліджувати залежність траєкторій від початкових положень і швидкостей, а також оцінювати збереження механічної енергії системи.

Програма розроблена мовою C++ із використанням бібліотеки SFML для графічного відображення та CMake для конфігурації й збирання проєкту.

### Основні можливості

- Моделювання гравітаційної взаємодії кількох тіл.
- Відображення тіл різними кольорами.
- Візуалізація траєкторій руху.
- Вибір одного з трьох наборів початкових умов.
- Зміна гравітаційної сталої та кроку чисельного інтегрування.
- Обчислення кінетичної, потенціальної та повної механічної енергії.
- Відображення часу симуляції та максимальної відносної похибки енергії.
- Призупинення, продовження та перезапуск симуляції.

Програма використовує умовні фізичні параметри, тому її призначення — демонстрація принципів гравітаційної взаємодії та чисельного моделювання, а не точне прогнозування руху реальних небесних тіл.

## 2. Технології

- **C++20** — основна мова програмування.
- **SFML 3** — створення вікна, обробка подій, відображення тіл, тексту й траєкторій.
- **CMake** — конфігурація та збирання проєкту.
- **vcpkg** — керування залежностями проєкту.
- **Visual Studio** — середовище розробки.

## 3. Встановлення та запуск

Для збирання проєкту необхідні Visual Studio з підтримкою C++, CMake, vcpkg та бібліотека SFML.

### Порядок запуску

1. Відкрити папку проєкту в середовищі, яке підтримує CMake.
2. Переконатися, що залежність SFML встановлена через vcpkg.
3. Перевірити налаштування `CMakePresets.json` і шлях до toolchain-файлу vcpkg.
4. Виконати конфігурацію проєкту через CMake.
5. Зібрати виконуваний файл.
6. Запустити програму.

Для роботи текстового інтерфейсу потрібен файл шрифту:

`resources/fonts/arial.ttf`

Шрифт має бути доступний за шляхом, який використовує програма під час запуску. Якщо в `CMakeLists.txt` налаштовано копіювання ресурсів у папку збирання, файл шрифту буде копіюватися автоматично.

## 5. Математична модель

### 5.1. Закон всесвітнього тяжіння

Гравітаційна взаємодія двох тіл описується законом всесвітнього тяжіння Ньютона:

F = G\frac{m_i m_j}{r^2}

де:

- (F) — сила гравітаційного притягання;
- (G) — гравітаційна стала моделі;
- (m_i), (m_j) — маси тіл;
- (r) — відстань між тілами.

У програмі використовується умовне значення гравітаційної сталої, яке можна змінювати під час симуляції.

**Де використовується:** функція `computeAccelerations()`.

### 5.2. Вектор відстані між тілами

Для визначення напрямку гравітаційної взаємодії обчислюється вектор між двома тілами:

Delta vec r=vec r_j-vec r_i

У двовимірній моделі:

Delta x=x_j-x_i

Delta y =y_j-y_i


Відстань між тілами визначається за теоремою Піфагора:


r=sqrt{(Delta x)^2+(Delta y)^2}

У коді для роботи з координатами використовуються об'єкти `sf::Vector2<double>`.

**Де використовується:** функції `computeAccelerations()` і `calculatePotentialEnergy()`.

### 5.3. Згладжування відстані

Для уникнення надмірних прискорень під час дуже близького зближення тіл використовується параметр згладжування \(\varepsilon\):

r_s^2=(Delta x)^2+(Delta y)^2 + var epsilon^2

Відповідно:


r_s=sqrt{r_s^2}


Цей підхід запобігає діленню на нуль і зменшує чисельні проблеми при малих відстанях.

Згладжування змінює класичну модель гравітації на малих відстанях, тому отримані результати є наближеними.

**Де використовується:** функції `computeAccelerations()` і `calculatePotentialEnergy()`.

### 5.4. Прискорення тіл

Згідно з другим законом Ньютона:


vec F = m\vec a


З урахуванням гравітаційної взаємодії прискорення одного тіла відносно іншого визначається формулою:

vec a_i=Gm_j\frac{Delta vec r} {r_s^3}


де r_s — згладжена відстань між тілами.

Для системи з кількох тіл прискорення кожного тіла дорівнює сумі внесків від усіх інших тіл:


vec a_i=sum_{j \ i}
Gm_j\frac{vec r_j-vec r_i}{r_{s,ij}^3}


Програма перебирає пари тіл і враховує взаємний вплив кожної пари.

**Де використовується:** функція `computeAccelerations()`.

### 5.5. Оновлення швидкості та положення

Для чисельного моделювання руху використовується метод leapfrog. Він послідовно оновлює швидкість і положення тіла.

Спочатку швидкість змінюється на половину кроку часу:

vec v_{t+frac{Delta t}{2}} = vec v_t+vec a_t\frac{Delta t}{2}

Потім оновлюється положення:

vec r_{t+\Delta t}
vec r_t+ vec v_{t+ frac{ Delta t}{2}} Delta t


Після переміщення тіл повторно обчислюються прискорення, а швидкість оновлюється ще на половину кроку:

vec v_{t+Delta t} = vec v_{t+frac{Delta t}{2} + vec a_{t+ Delta t} frac{ Delta t}{2}


Метод дозволяє отримувати наближені траєкторії руху, використовуючи послідовні невеликі кроки часу.

**Де використовується:** функція `updatePhysics(double dt)`.

### 5.6. Кінетична енергія

Кінетична енергія характеризує енергію руху тіла:

E_k=frac{mv^2}{2}

У двовимірній моделі квадрат швидкості визначається як:

v^2=v_x^2+v_y^2

Для всієї системи кінетична енергія дорівнює сумі енергій усіх тіл:


E_k=sum_ifrac{m_i}{2} (v_{x,i}^2+v_{y,i}^2)


**Де використовується:** функція `calculateKineticEnergy()`.

### 5.7. Потенціальна енергія

Гравітаційна потенціальна енергія пари тіл у використаній моделі визначається формулою:


E_p=-G\frac{m_i m_j}{r_s}


Повна потенціальна енергія системи обчислюється як сума енергій усіх унікальних пар тіл:


E_p=-G sum_{i<j}frac{m_i m_j}{r_{s,ij}}


Знак мінус відповідає прийнятому визначенню гравітаційної потенціальної енергії, за якого вона дорівнює нулю на нескінченній відстані.

**Де використовується:** функція `calculatePotentialEnergy()`.

### 5.8. Повна механічна енергія

Повна механічна енергія системи є сумою кінетичної та потенціальної енергій:

E=E_k+E_p

Для ідеальної ізольованої системи повна механічна енергія зберігається. У чисельній моделі можливі відхилення через наближене інтегрування, крок часу та згладжування гравітації.

**Де використовується:** функція `calculateTotalEnergy()`.

### 5.9. Відносна похибка енергії

Для оцінювання збереження механічної енергії використовується відносна похибка:

delta_E= frac{|E-E_0|}{|E_0|}

де:

- E_0 — початкова повна енергія;
- E — поточна повна енергія.

Програма визначає найбільше значення похибки за час симуляції. Чим меншою є похибка за однакових умов експерименту, тим краще чисельний розрахунок зберігає початкову енергію.

Якщо початкова енергія дорівнює нулю або дуже близька до нього, відносна похибка може бути невизначеною або нестабільною, тому такі випадки потребують окремої обробки.

**Де використовується:** функція `updatePhysics(double dt)`, яка викликає `calculateTotalEnergy()` та оновлює змінну максимальної похибки.

## 6. Основні функції програми

| Функція | Призначення |
| `resetSimulation()` | Створює тіла відповідно до вибраного набору початкових умов і скидає стан симуляції. |
| `computeAccelerations()` | Обчислює гравітаційні прискорення тіл. |
| `updatePhysics(double dt)` | Оновлює швидкості, положення, час, траєкторії та статистику похибки енергії. |
| `calculateKineticEnergy()` | Обчислює сумарну кінетичну енергію. |
| `calculatePotentialEnergy()` | Обчислює сумарну гравітаційну потенціальну енергію. |
| `calculateTotalEnergy()` | Повертає суму кінетичної та потенціальної енергій. |
| `formatNumber()` | Перетворює числові значення на форматований текст. |
| `drawText()` | Відображає текст у графічному вікні. |
| `drawTrajectories()` | Малює збережені траєкторії тіл. |
| `drawBodies()` | Малює тіла у вигляді кіл. |
| `drawInterface()` | Відображає інформаційну панель і поточні показники симуляції. |
| `main()` | Ініціалізує програму, обробляє події, керує оновленням фізики та відображенням кадрів. |

## 7. Структура проєкту

```text
lb5/
├── main.cpp
├── CMakeLists.txt
├── CMakePresets.json
├── vcpkg.json
├── resources/
│   └── fonts/
│       └── arial.ttf
└── build/
```

### Призначення файлів

- **`main.cpp`** — містить структуру тіла, математичну модель, функції розрахунку фізики, відображення та керування програмою.
- **`CMakeLists.txt`** — описує ціль збирання, стандарт C++ і підключення компонентів SFML.
- **`CMakePresets.json`** — зберігає параметри конфігурації CMake, зокрема генератор і шлях до toolchain-файлу.
- **`vcpkg.json`** — описує зовнішні залежності проєкту.
- **`resources/fonts/arial.ttf`** — файл шрифту, який використовується для відображення тексту.
- **`build/`** — каталог для згенерованих файлів конфігурації та збирання.
